# Selectable

Framework-agnostik, sıfır bağımlılıklı, premium hissiyatlı select bileşeni.

**Hedef:** select2 kadar esnek, bootstrap-select kadar özellikli — ama jQuery/Bootstrap
bağımlılığı yok, host sayfanın CSS'i ne olursa olsun tasarımı bozulmuyor.

## Durum

🚧 Araştırma + tasarım aşaması. Raporlar: `docs/research/`

## Geliştirme

```bash
npm install
npm run dev    # demo oyun alanı
npm run build  # dist/ (ESM + CJS + IIFE + CSS)
npm test
```
